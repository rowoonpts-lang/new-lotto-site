# Lotto Platform Development

기존 운영 중인 PHP 기반 로또 플랫폼을 안정적으로 정리하고 개선하기 위한 프로젝트입니다.

## 프로젝트 목표

- 기존 기능 유지
- 코드 구조 정리
- 유지보수성 향상
- 보안 위험 점검
- GitHub 중심의 변경 이력 관리
- Cafe24 운영 환경과의 호환성 유지

## 개발 원칙

1. 기존 운영 기능을 깨뜨리지 않습니다.
2. 한 번에 하나의 기능만 수정합니다.
3. 수정 전에 현재 코드를 먼저 분석합니다.
4. 대규모 구조 변경은 단계적으로 진행합니다.
5. 모든 변경은 Git으로 기록합니다.

## 기술 환경

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- GitHub
- GitHub Codespaces
- Cafe24 Hosting

## 주의사항

- `data/` 폴더에는 세션, 캐시, 업로드 파일이 포함될 수 있습니다.
- 운영 설정 파일과 데이터베이스 정보는 외부에 공개하지 않습니다.
- 테스트 파일과 서버 점검 파일은 사용 여부를 확인한 뒤 정리합니다.
