# Project Structure

## 프로젝트 개요

본 프로젝트는 기존 운영 중인 PHP 기반 로또 플랫폼을 안정적으로 리팩토링하기 위한 프로젝트입니다.

기존 기능을 유지하면서 코드의 가독성, 유지보수성, 확장성을 향상시키는 것을 목표로 합니다.
